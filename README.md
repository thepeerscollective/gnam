# GNAM · trattoria, kraków

Concept restaurant site by the peers collective. Next.js 15, no backend (booking is a demo).

- `lib/menu.ts` – the whole menu. flip `finito: true` when a dish sells out, `bestseller: 1–6` for home, `nonnaPick` for the red circle.
- `lib/dict.ts` – every word in PL + EN.
- `public/img` – photos (webp).

```
npm install
npm run dev
```
